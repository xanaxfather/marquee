Import settings

    Welcome to Marquee

    Marquee shows the movie or show you’re watching on your Discord profile, with artwork, episode names and progress. Setup takes about two minutes.

    Skip setup

    Connect Discord

    Discord needs an application for Marquee to post under. Its name is what appears after “Watching”.

    1. Open the Developer Portal and choose New Application.
    2. Name it what you want shown, like “TV” or “Movies”.
    3. Copy the Application ID and paste it here.

    Connect TMDB

    The Movie Database identifies your files and supplies artwork. A personal key is free.

    1. Sign in at themoviedb.org/settings/api.
    2. Request an API key (choose “Personal use”).
    3. Paste the API Key or Read Access Token.

    Set up your players

    Marquee switches on the connection each installed player needs. Quit and reopen the player afterwards.

    You’re all set

    Play something and it appears on Discord within a few seconds. Marquee lives in the menu barsystem tray.
